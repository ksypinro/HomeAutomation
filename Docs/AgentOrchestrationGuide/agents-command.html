02 · Command construction

Turn context into a governed command.

These agents compose the model package, draft a structured command, validate it with deterministic policy, plan or execute it, and produce safe fallback or response outcomes.

13 agent implementations5 governed command gates

The command spine

Once a target and capability are known, most nodes run sequentially because each consumes the previous artifact.

composeInstruction packageCompact candidates, canonical facts, RAG evidence, tools, and prompt budget.
generateCommand draftStructured target, intent, capability, command, parameters, and confidence.
validateSafety & parametersTarget support, risk floor, command legality, ranges, and enums.
governConfirmation & planSensitive or high-risk work pauses; allowed work becomes an execution plan.
finishExecute or explainMock mutation, ready plan, clarification, unsupported, or summary.
Fail closed, with one nuance

The graph planner marks safety validation, parameter validation, confirmation, and mock execution as safety gates; execution planning is required and separately treated as mandatory by policy. A missing/failed mandatory node must produce a safe terminal result, not device mutation.
