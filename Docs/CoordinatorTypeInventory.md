## Classification Rules

- `dependency`: services, agents, workers, resolvers, registries, clients, factories, validators, mappers, RAG infrastructure, telemetry infrastructure, graph infrastructure, and coordinators.
- `runtime-scoped`: per-run or per-graph state that should be created by run/session orchestration, not shared globally.
- `pure model`: DTOs, payloads, request/response structs, snapshots, plans, and result values; local construction remains correct.
- `fixture`: evaluation/test data models owned by evaluation setup.
- `test-only`: test support types outside production sources.
